# 一、Windows日志

## 1，事件日志

每个记录事件的数据结构中包含了9个元素（可以理解成数据库中的字段）：日期/时间、事件类型、用户、计算机、事件ID、来源、类别、描述、数据等信息

> 查看方式：Win + R，输入eventvwr.msc

![image-20261024221259008](系统日志分析.assets/image-20261024221259008.png)

应用程序 中又有这几种类型

![image-20261027192431914](系统日志分析.assets/image-20261027192431914.png)

对应日志文件的位置：

```bash
#应用程序
%SystemRoot%\System32\Winevt\Logs\Application.evtx
#系统
%SystemRoot%\System32\Winevt\Logs\System.evtx
#安全日志
包含安全性相关的事件，如用户权限变更，登录及注销，文件及文件夹访问，打印等信息
%SystemRoot%\System32\Winevt\Logs\Security.evtx
```
